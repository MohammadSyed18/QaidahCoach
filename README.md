# QaidahCoach

An educational practice toolkit for foundational Quranic Arabic reading concepts: madd, qalqalah, ghunnah, ikhfa, idgham, and iqlab. Python generates deterministic, carefully labeled sample exercises with accessible transliteration and explanations; TypeScript manages validated spaced-review progress.

Run `python3.12 -m unittest discover -s tests -v`, `python3.12 -m qaidahcoach.cli madd --seed 7`, `npm install`, `npm test`, and `npm run build`.

The examples are limited instructional samples and may not cover contextual recitation differences. This application is not a substitute for learning with a qualified teacher.
